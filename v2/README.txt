VYRON SUMMIT v2 — no install, no server needed.
1. Put your video in this folder, named exactly: intro.mp4  (next to index.html)
2. Double-click index.html.
Edit event details, links, speakers, logo path in js/config.js.
Optional: put the college logo at assets/images/dempo-logo.png and a poster image path in js/config.js (teaserPoster).
Fonts load from Google Fonts when online; the site falls back to system fonts offline.
